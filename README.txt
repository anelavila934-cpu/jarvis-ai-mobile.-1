JARVIS AI MOBILE 0.1 - WEB APP

Esta carpeta contiene una PWA (aplicación web instalable), no una APK.
Puedes abrir index.html en el navegador para probar la interfaz; el dictado de voz puede requerir HTTPS y un navegador compatible.

PARA INSTALAR COMO APP:
1. Publica estos archivos en un alojamiento HTTPS estático (por ejemplo GitHub Pages).
2. Abre la dirección HTTPS en Chrome Android.
3. Menú ⋮ > Instalar aplicación o Añadir a pantalla de inicio.

La versión actual es una demo local: chat con respuestas predefinidas, dictado de voz si el navegador lo soporta y voz sintetizada. No contiene IA real ni envía tus mensajes a un servidor.
No pegues claves API en el HTML ni compartas claves privadas.
